📖 StegoLab Quick Start & Architecture

Overview

StegoLab is a modular image steganography research environment implementing 3 algorithms with varying levels of security and complexity.

Algorithms

  • Algorithm 1 (Basic LSB): Sequentially modifies least significant bits. Highly efficient, deterministic.
  • Algorithm 2 (Randomized LSB): Fisher-Yates shuffle seeded by secret key hash. Resists positional analysis.
  • Algorithm 3 (Edge-Adaptive): Dynamically scales embedding depth (1 to 3 bits) using 3x3 local luminance variance in textured regions.
